# One-Star Review of Something Essential

A deadpan one-star review of sleep, an everyday essential.

## Entry

> One star. Sleep takes eight hours a day, offers no refund, and every morning I wake up still tired, as if it did the bare minimum and left early.

145 characters, one line, no exclamation marks. The grievance is real
(eight hours, no refund, still tired) and the turn lands in the last few
words: sleep did the bare minimum and left early.

## Program

`main.py` (Python 3) writes the review to `/output/entry.txt`. The text is
a constant, so every run is byte-identical. Built-in self-checks enforce
the gate before writing: 1–160 characters, single line, no leading or
trailing whitespace, no exclamation marks, at most 160 UTF-8 bytes.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
